RING OUT

Line up a gap, then fire. Order matters.

How to play

Goal. Spin the rings so a gap lines up, then fire every pin out of the circle. Do it in an order that keeps a lane open.

Rings. Drag a ring around the center. It snaps to a step, and each step costs one move. A badge shows −N while you drag. Letting go far outside the ring cancels the drag.

Pins. Tap a pin to launch it. Launching is free. A pin escapes only when every ring outside it has a gap on that line, with no pin in the way. Green ticks are open lanes. Red ticks are blocked.

Order. When a pin escapes, its ring kicks forward one step and a new gap opens where it left. Shooting a clear pin can close the lane another pin needed. Clear the inside first when both lanes are green.

Colors. Later levels add gates. A gate only lets the matching color through. White pins need a plain gap. Each gate has a shape as well as a color: coral triangle, teal diamond, gold circle.

Hearts and moves. A blocked launch costs a heart. You start with 3. You also lose if the last move leaves no clear pin. If a pin is already lined up, you can still launch it with 0 moves.

Keys. Arrows or WASD turn the selected ring. Tab cycles pins. Space launches. Z undoes, R restarts, H hints, M mutes, Esc pauses.
